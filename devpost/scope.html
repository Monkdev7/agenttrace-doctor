AgentTrace Doctor

Scope · status: draft · Markdown (scope.md) is canonical
An evidence-first debugging tool that loads an AI agent's execution trace, detects suspicious patterns with deterministic rules, and explains each finding with a direct link to the exact events that triggered it. No LLM, no API key, no network.

User → Core Loop → Proof

The User

A student or indie dev whose agent just looped or kept erroring, and who can't see why from raw logs.

→

Core Loop

Load a sample or upload JSON → see the run as a timeline → detectors list findings → read evidence + fix → export report.

→

The Proof

Click a finding and watch it light up the exact events that justify it — and the same evidence lands in the exported Markdown report.

The Unique Kernel

Every finding is backed by evidence, not a model's opinion. The evidence is the product. Delete the event-level evidence linking and the facts/explanation separation, and this becomes just another chatbot — so that separation is the thing to protect.

Anatomy of a Finding (the visual differentiation)

Every finding keeps these four parts visually distinct, so a reader can never mistake an interpretation for a fact:

1 · Observed fact

Tool search was called 4 times with identical arguments.

2 · Supporting evidence

Events #3, #5, #7, #9 — click to highlight on the timeline.

3 · Potential explanation

May indicate the agent is stuck in a loop — possible, not certain.

4 · Suggested fix

Add a repeat guard or vary the query; check why the result isn't advancing the plan.

Scope Boundary

Now — in the MVPNow
  • Owned minimal trace format: ordered events with id, type (tool_call/tool_result), tool_name, args, status, optional error, optional call_id. Fields conditional on type.
  • Upload + bundled samples, validated with clear, human-readable errors.
  • Parsing layer → normalized internal representation; seam left open for future adapters.
  • Stable JSON normalization of args so key order never causes a false mismatch.
  • Detector 1 (mandatory): repeated identical tool calls → possible loop. Exact repeats only.
  • Detector 2 (mandatory): explicit tool errors → surfaces error evidence.
  • Execution timeline + finding → timeline linking.
  • Export a Markdown report (the only export format in the MVP).
  • Fully local: no sign-up, no API key, no network.
Later — worth doing, not nowLater
  • Detector 3 (stretch): same tool erroring N+ times. Additive only — must not delay the core.
  • PDF and other export formats.
  • Adapters for LangSmith, OpenTelemetry GenAI spans, OpenAI tool-call logs.
  • Optional LLM narration — strictly additive, never required.
  • General cycle / repeating-subsequence detection.
  • Deployment (optional for submission).
Explicitly cut — with a reasonCut
  • LLM-based diagnosis — the "generic chatbot" failure mode the kernel exists to avoid; non-reproducible.
  • General cycle detection — too ambiguous to define reliably; false-positive risk undermines the trust-first promise.
  • Real third-party trace ingestion — a full parser would eat the whole budget; the seam stays open without paying now.
  • Accounts / API keys / back end — local and stateless by design.

Acceptance Criteria

  1. Loads a bundled sample trace and renders it as a clear, ordered execution timeline.
  2. Uploads are validated; invalid JSON is rejected with a clear, human-readable error.
  3. Detector 1 (mandatory) flags 2+ identical tool calls and cites exact event IDs.
  4. Detector 2 (mandatory) flags every status: error result and shows the error as evidence.
  5. Every finding cites supporting event IDs, states the fact, explains the rule, and separates facts from interpretations.
  6. Each finding visually separates the four parts: fact · evidence · explanation · fix.
  7. Selecting a finding highlights its supporting events on the timeline.
  8. Exports a Markdown debugging report containing the findings and their evidence.
  9. Primary demo path runs fully locally — sample → diagnosis → export — with no account, key, or network call.
  10. Stretch: Detector 3 flags the same tool erroring N+ times, with the same citations and separation.
